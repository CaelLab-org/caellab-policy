本政策与 [虚舟实验室 隐私权政策](/public-policy/privacy-rights) 是一个不可分割的整体——那边讲的是所有平台共同遵守的部分，这里讲 XMUER 两个站各自具体收什么、怎么用。

原则还是那几条：能不收就不收，收了写清楚，你随时可以问、可以关、可以走。

### 适用站点

- [XMUER 论坛](https://forum.xmuer.online/) — 以编程为核心的技术社区；
- [XMUER Coding Community](https://coding.xmuer.online/) — Scratch 作品创作与分享社区。

两个站都通过 [CaelLabID](https://id.caellab.com) 统一登录，我们不接收也不保存你的密码；首次登录时会为你生成或沿用你的用户名，并保存 CaelLabID 提供的平台标识（`sub`）作为账号绑定依据。

---

### 我们收集的信息

**XMUER 论坛**

- 登录相关信息：登录后生成的必要 Cookie，用于维持登录状态；
- 个人资料信息：你主动填写或上传的昵称、个人简介、头像等；
- 社区互动信息：你发布的主题帖、回复、上传的附件，以及你参与的私密讨论；
- 访问日志信息：IP 地址、浏览器类型及版本等设备与网络信息。

**XMUER Coding Community**

- 作品信息：你上传的 SB3 作品文件、封面、标题、简介与更新日志；
- 社区互动信息：你发表的评论、回复、留言板留言、话题，以及点赞、收藏、关注等关系；
- 使用记录：浏览记录、停留时长等，用于内容推荐与排序；
- IP 属地：根据 IP 判断的属地信息（默认精确到省/地区，可调整），用于在评论等内容旁显示属地，是否显示、显示到什么精度由你在设置中决定；
- 访问日志信息：IP 地址、浏览器类型及版本等设备与网络信息。

---

### 我们如何使用信息

- **保障基础服务**：登录验证、内容展示、社区互动等核心功能；
- **个性化推荐**：根据你的互动记录（浏览、点赞、收藏、停留时长等）了解偏好，为你推荐可能感兴趣的内容。**你可以在设置中关闭个性化推荐**：关闭后你的使用记录不再用于推荐，排序退回热度与时间；浏览历史这类你自己也会看的功能数据仍会保留，足迹页可以随时清空；
- **安全防护**：通过 IP 地址等信息识别恶意刷屏、广告发布、自动化攻击等行为；IP 属地显示也是这件事的延伸——让每条内容能回答「谁在什么时候发的」，同时把是否展示的决定权留给你；
- **合规配合**：在法律法规强制要求或有权机关依法调取的情况下，配合相关调查工作。

我们不会出售或出租你的个人信息，也不会将其提供给第三方用于推广第三方的产品或服务。

### 第三方服务

为保障服务正常运行，两个站接入了以下第三方服务：

- **XMUER 论坛**：[Cloudflare](https://www.cloudflare.com/)（网络分发与安全防护）、Cloudflare Turnstile（人机验证，拦截自动化注册与垃圾信息）、Pusher（实时通信，用于在线状态与消息推送）；
- **XMUER Coding Community**：[Cloudflare](https://www.cloudflare.com/)（网络分发与安全防护）。

这些服务可能接触到访问时产生的网络信息（如 IP 地址、浏览器类型），其处理规则参见各自公布的隐私政策。

### 你的权利

**开关都在你自己手里（Coding Community）**

- 个性化推荐：设置页可以一键关闭；
- IP 属地：可以整体关闭，也可以按位置（个人主页 / 内容 / 评论）和精度分别调整。

**行为记录的保留期限**

用于个性化推荐的使用记录保留不超过 **180 天**，到期自动删除或匿名化。

**账号注销（论坛）**

鉴于本论坛基于 [Flarum](https://130.wiki/wiki/Flarum) 系统搭建，受其技术架构限制，部分历史数据无法彻底删除，平台将通过最大化脱敏方式保障你的权益。通过 [forum@caellab.com](mailto:forum@caellab.com) 提交申请（邮件标题注明【账号注销请求】，正文提供注册邮箱与账号昵称）后，我们将在 **7 个自然日**内完成：

- 匿名化处理你发布的主题帖及回复（帖子内容保留，删除整个个人主页）；
- 删除你的头像、个人简介等全部个人资料；
- 注销账号绑定关系：注册邮箱将被释放，可再次用于新账号注册；原账号不可找回。

**账号注销（Coding Community）**

账号与数据删除请求请发送至 [xcc@caellab.com](mailto:xcc@caellab.com)，我们将在 **7 个自然日**内处理。
