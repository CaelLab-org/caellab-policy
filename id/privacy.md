### 政策概述

CaelLabID（以下简称"本平台"）是虚舟实验室的统一身份认证系统——你在各家服务里的身份都从这儿来。正因为它处在最核心的位置，我们对它要求反而更严：能用别的东西解决的绝不多存一份，能不给应用的绝不替你给。

本隐私政策说明我们在提供身份认证服务过程中，如何收集、使用、存储和保护相关信息。

使用本平台即表示你理解并同意本政策的约定。如果你不同意，请停止使用本平台。

### 我们收集的信息

**注册与账户信息**

注册时你需要提供邮箱地址、出生日期、性别和所在国家/地区等，并设置密码。密码经加密存储，连我们自己也无法还原。你的用户名、头像、个人简介等资料由你主动填写。

如果你未满 16 周岁，注册时还需提供监护人邮箱；我们会向该邮箱发送同意确认邮件，并以监护人邮箱作为你的账户邮箱。

**安全与验证信息**

为保护账号安全，你可以自愿启用二次验证（动态口令、邮箱验证码、恢复码）或通行密钥，并可为账号设置临时密钥作为紧急登录凭证。启用后我们会保存相应的验证密钥或凭证公钥，用于登录时校验。

**设备记录**

为识别异常登录，我们会记录你登录时使用的设备信息（设备名称、IP 地址、浏览器标识等），并保存你信任的设备列表，供你在仪表盘中查看与撤销。

**授权与认证信息**

当你通过 CaelLabID 登录第三方应用时，我们会记录授权关系——包括你授权了哪个应用、授权了哪些权限（scope）、以及授权时间。我们不会记录你在第三方应用中的具体操作。

**OAuth Token 信息**

为维持认证服务正常运行，我们会存储 Access Token 和 Refresh Token 的哈希值（不可逆）。Token 本身不会被我们保存。

**Cookie**

CaelLabID 使用以下 Cookie 维持登录状态与设备识别：

- **登录会话 Cookie**（`CAELLABID_SESSION`）：维持你的登录状态；
- **设备标识 Cookie**（`caellab_device_id`）：识别你常用的设备，用于受信设备管理与异常登录提醒；
- **登录状态标记 Cookie**：在统一登录流程中标记登录结果，供站群内其他站点读取。

这些 Cookie 仅在实现上述功能所需的期限内有效。

**通知信息**

当你触发安全提醒（如新设备登录）或系统公告时，我们会向你发送站内通知；在你开启邮件提醒时，还会通过邮件送达。

**账号申诉材料**

如果你通过账号申诉流程找回账号，我们会在该流程中收集你填写的账号信息、出生日期与性别（用于核验身份）、联系方式，以及你上传的证明材料等；这些材料仅用于申诉核验。

**日志信息**

为保障服务安全和排查故障，服务器会记录访问日志，包括 IP 地址、访问时间、请求路径、浏览器类型等。你的账户操作（如登录、修改资料、授权与撤销授权）也会被记录为活动日志，其中包含操作时间、IP 地址、设备信息与变更内容。

### 我们如何使用信息

- **提供身份认证服务**：验证你的身份、管理授权关系、签发和验证 Token；
- **安全防护**：识别异常登录、暴力破解、自动化攻击等行为，保护平台和用户账号安全；
- **服务优化**：分析使用数据以改进平台性能和用户体验；
- **合规响应**：在法律法规要求或有权机关依法提出请求时，配合提供必要信息。

我们不会出售或出租你的个人信息，也不会将其提供给第三方用于推广第三方的产品或服务。我们会使用你的信息来提供、维护和改进我们的服务。

### 跨应用隐私保护

CaelLabID 为每个应用独立生成用户标识（`subject_id`）。这意味着：

- 同一个用户在不同应用中拥有不同的标识
- 应用之间无法通过 CaelLabID 的标识关联同一用户
- 你在应用 A 中的身份信息不会被应用 B 获取

这是我们的核心隐私设计原则。

### 信息共享

我们严格限制信息共享，仅在以下情形下向第三方提供信息：

- **你的明确授权**：当你在授权页面同意将信息共享给某个应用时；
- **服务提供商**：向提供服务器托管、技术支持等服务的合作方共享必要信息，且要求其遵守同等保护标准；
- **法律法规要求**：在法律法规强制要求或有权机关依法提出请求时，配合提供必要信息；
- **权益保护**：为保护本平台、用户或公众合法权益免受侵害，在必要范围内披露信息。

具体第三方信息共享情况请参阅[第三方信息共享清单](/id/third-party-sharing)。

### 你的权利

**查看与管理**

你可以随时登录 [CaelLabID](https://id.caellab.com) 查看你的账户信息、管理已授权的第三方应用，并在 [仪表盘](https://id.caellab.com/dashboard) 中撤销对任何应用的授权。

**注销账号**

你可以申请注销 CaelLabID 账号。注销后：

- 你的账户信息和授权关系将被删除
- Access Token 和 Refresh Token 将立即失效
- 你在各应用中的标识（`subject_id`）将被删除
- 第三方应用可能仍保留其自身系统中的登录状态

注销申请请发送邮件至 [id@caellab.com](mailto:id@caellab.com)，我们将在 **7 个自然日**内处理。

**数据导出**

如需导出你的账户数据，请通过上述邮箱联系我们。

### 信息存储与保护

- **存储地点**：用户数据存储在虚舟实验室自有服务器（通常位于香港地区），通过 [Cloudflare](https://www.cloudflare.com/) 进行网络分发与安全防护；
- **加密保护**：所有数据传输强制使用 HTTPS 加密；密码等敏感信息采用哈希加密存储；
- **Token 安全**：Token 以 SHA-256 哈希值存储，服务端不保留明文；
- **保留期限**：账户信息保留至账号注销；访问日志仅在保障安全与排查故障所必需的期限内保留；授权记录保留至授权撤销或账号注销。

### 儿童隐私保护

我们在注册时会收集出生日期与性别，用于判断用户是否未成年，并据此提供相应保护。本政策所称儿童，指未满 16 周岁的用户；如你所在地区法律法规对儿童的年龄标准另有规定，则按当地标准执行。

如你属于上述儿童范围，请在监护人知情并同意的前提下使用本平台；注册时需提供监护人邮箱，由我们向监护人发送同意确认邮件。我们不会将儿童的个人信息用于本政策约定之外的其他用途；如发现在未取得监护人同意的情况下收集了儿童的个人信息，将立即删除。
